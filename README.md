# Last-Mile Route Duration Prediction

UTS 42172 Introduction to Artificial Intelligence — AT1, Example II (regression)
Author: Le Binh Nguyen (26205599)

## Problem
Route-planning software gives every delivery route an optimised stop sequence, but drivers
often change it, so the real time a route takes differs from the plan. This project
predicts the **actual duration of a last-mile delivery route** using only information
available before the route starts, and compares two machine-learning techniques
against simple baselines.

## Data
Konovalenko, A., Hvattum, L. M., & Iversen, K. A. H. (2024). *Last-mile delivery route
deviations dataset: Planned vs. actual routes* (Version 1) [Data set]. Mendeley Data.
https://doi.org/10.17632/kkwgfvmtxn.1

Real, anonymised records from a logistics company operating in Norway and Denmark:
19,647 routes, 400 drivers, 32 weeks.

The dataset is licensed CC BY-NC-ND 4.0 and is **not included** in this repository.
Download `routes_performance.xlsx` from the DOI above and place it in
`MyDrive/IntroToAI/AT1_II/data/`.
